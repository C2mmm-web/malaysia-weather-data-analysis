# Malaysia Weather Data Analysis

A group data analysis project using 51,693 cleaned weather records from selected locations in Kuala Lumpur and Pulau Pinang.

## Project focus

- Auditable data cleaning through imputation flag columns
- Geographic coverage and data-quality checks
- Feature engineering for temperature, gust, rainfall, pressure, and UV analysis
- Comparison of humidity and dew point for outdoor-comfort communication

## My contribution

Chen Zimo worked on the data dictionary, data cleaning, imputation flags, location-coverage checks, and feature engineering used in the final group analysis.

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Files

- `full_group_weather_analysis.ipynb`: complete group notebook with the full workflow, analysis, results, limitations, and contribution record
- `malaysia_weather_cleaned.csv`: cleaned dataset retained with the project
- `requirements.txt`: required Python packages

The notebook preserves the original group analysis and saved outputs. Some source-stage files referenced during the original workflow are not included in this repository.

## Main conclusion

Humidity is the clearer public-facing indicator for outdoor comfort, while dew point is useful as a supporting technical measure. The results describe this dataset and should not be generalized to all of Malaysia.
